国語マスター プライバシーポリシー

最終更新日：2026年10月29日

本ポリシーは、i want（以下「当方」）が提供する iOS アプリ「国語マスター」（以下「本アプリ」）における、利用者の情報の取り扱いについて定めるものです。

1. 端末内に保存する情報

本アプリは、次の学習情報を利用者の端末内に保存し、問題の報告を送るときも送信しません。

  • 書き込み・解答・成績：本アプリ内の保存領域に保存します。
  • 設定：端末内の設定領域に保存します。
  • 単語帳で覚えた語：覚えた語の記録を端末内に保存します。
  • お知らせの既読状況：どのお知らせまで読んだかを端末内に保存します。
  • 評価ダイアログに関する情報：表示条件に使う利用時間と、表示したアプリの版を端末内に保存します。

2. 通信する情報

  • 本アプリは、お知らせを表示するために、お知らせの JSON（https://ottub.github.io/kokugo/notices.json）を読み込みます。
  • 本アプリは、i want のアプリ一覧（https://ottub.github.io/apps.json）を読み込みます。一覧から App Store のページを開く場合は、Apple の画面に移動します。
  • お知らせとアプリ一覧の読み込みでは、利用者が入力した情報を当方へ送信しません。通常の通信として、接続先の GitHub Pages サーバーには IP アドレスなどが届くことがあります。
  • 評価ダイアログには Apple の標準機能（StoreKit の requestReview）を使います。
  • 解説画面から問題の報告を送るときは、iCloud（CloudKit）または利用者が選んだメールを使います。報告を送る前の iCloud の確認や、送る情報については「問題の報告」をご覧ください。

3. ご意見・不具合のメール

設定の「ご意見・不具合を送る」から、利用者が内容を確認したうえで、端末のメール機能を使って当方へ送信できます。メールの宛先は donstloujx@gmail.com です。メール本文にはアプリの版・端末の機種・iOS の版が自動で入ります。送信するかどうかは利用者が決められます。

4. 問題の報告

解説画面の設問ごとにある「この問題を報告」から、答えや解説、問題文、図や表示について気になった点を送れます。設定の「ご意見・不具合を送る」は、これとは別のメール機能です。

  • 報告するかどうかは自由です。送らなくても、アプリを使えます。
  • 送信前に主な内容を確認できます。報告の種類、入力した文、冊子の情報、アプリや端末の情報、AIでの仕分けへの同意が画面に表示されます。
  • 自動では送りません。「送る」または「メールで送る」を選んだときに送信します。

送る情報

  • 入力した内容：「気になった点」に書いた文と、「どんなこと？」で選んだ報告の種類
  • 問題の情報：冊子ID、大問、題名、冊子の種類（問題冊子・解答冊子・解説）、頁、設問番号
  • アプリと端末の情報：アプリの版と build 番号、iOS の版、機種の型番、実行環境（iPhone・iPad または Mac）、文字サイズ
  • どちらの方法でも：AIでの仕分けを使ってよいかの選択
  • iCloud で送る報告：上記の内容に加えて、報告番号、送信を確定した日時、AIの説明の版
  • メールで送る報告：入力した内容、問題の情報、アプリと端末の情報、AIでの仕分けの選択が本文に入ります。アプリから送ると決めた報告をメールに切り替えた場合は報告番号も入り、iCloudで受け付け済みの日時や、アプリからも届いている可能性を知らせる文が入ることがあります。

メールを送信すると、メールアドレスや表示名などの送信者情報も開発者に届きます。iCloud で送る場合、メールアドレスは送りません。ただし iCloud の仕組みにより、送った人の iCloud アカウントごとに決まる識別子と受け付けた日時が報告に付きます。開発者がこの識別子から名前やメールアドレスを調べることはありません。

送らないもの：書き込み・解答・成績などの学習記録、端末の名前、位置情報、連絡先、写真、広告識別子、購入情報は報告に含めません。報告文に名前・学校名・連絡先などを書かないでください。

送り方と取り消し

CloudKit が利用できる場合は、報告画面を開いたときに iCloud の状態を確かめます。iCloud を使えないときや、送信機能を利用できないときはメールを選べます。「メールで送る」を選ぶとメールアプリが開き、内容を確かめて送信します。

アプリから送る報告は、送信を決めた時点で端末に保存されます。送信できないときは、アプリを開いている間、確定から7日まで送り直します。届く前なら「送るのをやめる」で取り消せます。7日たっても送れない報告は、次にアプリを開いたとき端末から削除します。iCloud で受け付けられた後は、報告本文を端末から削除し、報告番号などの記録を受け付けから90日まで残します。

使いみちと保存期間

報告は、問題や解説の誤り、表示の不具合を確認して直すことと、アプリの改善に使います。広告、販売、追跡には使いません。個々の報告への返信はしていません。

iCloud で受け付けた報告は、開発者が管理する Mac に取り出して確認し、受け付けから90日を過ぎたら iCloud とその Mac から削除します。メールで届いた報告も、受信から90日を過ぎたら削除します。削除作業の時期により、削除まで最大1か月ほどかかることがあります。Apple の iCloud 内部での保存は、Apple の方針に従います。報告をもとに直した内容は、個人が分からない形で開発記録に残ることがあります。

AIでの仕分け

報告画面の「AIでの仕分けに使ってよい」は、初期状態ではオフです。オンにした報告だけが仕分けの対象になり、オフのままでも報告を送れます。開発者が報告を読み、個人情報を取り除いて作った要約と、冊子や設問の情報、アプリの版、実行環境を OpenAI のAIによる仕分けに使います。要約と仕分け結果は、開発の確認を手伝う Anthropic のAIにも渡します。報告本文やメールアドレスはAIに渡しません。OpenAI と Anthropic は Apple 以外の会社です。渡した資料の扱いは、それぞれの会社の方針と、開発者が使うサービスの設定によります。AIの結果だけで問題や答えを変更することはありません。

削除・同意の取り消し

送った報告を削除したいとき、またはAIでの仕分けへの同意を取り消したいときは、「お問い合わせ」のメールアドレスへご連絡ください。報告を見つけるため、送った日時と内容（冊子IDや設問番号など）をお知らせください。メールで送った報告に報告番号があれば、あわせてお書きください。すでに終わった処理は、取り消せないことがあります。

5. 解析・追跡・第三者提供

本アプリには、Analytics・Firebase・広告 ID・App Tracking Transparency（ATT）を使った解析・追跡の道具は入っていません。広告配信やアクセス解析も行いません。

問題の報告を送るときは、選んだ方法に応じて Apple の iCloud（CloudKit）またはメールで開発者に届きます。AIでの仕分けを許可した報告の要約などは、AIでの仕分けに記載したとおり OpenAI と Anthropic のAIに渡します。これ以外の目的で情報を販売したり、第三者に提供したりすることはありません。

6. お子様のプライバシー

本アプリは高校生以上の学習者を主な対象としています。13歳未満の方が利用する場合は、保護者の方と一緒に本ポリシーをご確認ください。

7. 本ポリシーの改定

当方は、必要に応じて本ポリシーを改定することがあります。変更後の内容は、本アプリまたは本ページでお知らせします。
