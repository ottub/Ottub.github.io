地理マスター プライバシーポリシー

最終更新日：2026年11月6日

本ポリシーは、i want（以下「当方」）が提供する iOS アプリ「地理マスター」（以下「本アプリ」）における、利用者の情報の取り扱いについて定めるものです。

1. 端末内に保存する情報

本アプリは、次の学習情報を利用者の端末内に保存します。問題の報告を送るときも、これらは送信しません。

  • 模試・演習・手書きの記録：本アプリ内の保存領域に保存します。設定の「記録を消す」で消せます。
  • 設定：外観、ペンの既定色、模試中に決め手の表を開くか、紙面の文字の大きさなどを端末内の設定領域に保存します。
  • お知らせの既読状況：どのお知らせまで読んだかを端末内に保存します。
  • 評価ダイアログに関する情報：表示条件に使う利用時間と、表示したアプリの版を端末内に保存します。

2. 通信する情報

  • 本アプリは、お知らせを表示するために、お知らせの JSON（https://ottub.github.io/geography/notices.json）を読み込みます。
  • 本アプリは、i want のアプリ一覧（https://ottub.github.io/apps.json）を読み込みます。一覧から App Store のページを開く場合は、Apple の画面に移動します。
  • お知らせとアプリ一覧の読み込みでは、利用者が入力した情報を当方へ送信しません。通常の通信として、接続先の GitHub Pages サーバーには IP アドレスなどが届くことがあります。
  • 評価ダイアログには Apple の標準機能（StoreKit の requestReview）を使います。
  • 問題の画面から問題の報告を送るときは、利用者が選んだメールを使います。送る情報は「4. 問題の報告」をご覧ください。

3. ご意見・不具合のメール

設定の「ご意見・不具合を送る」から、利用者が内容を確認したうえで、端末のメール機能を使って当方へ送信できます。メールの宛先は donstloujx@gmail.com です。メール本文にはアプリの版・端末の機種・iOS の版が自動で入ります。送信するかどうかは利用者が決められます。

4. 問題の報告

  • 問題の画面の下の帯にある「報告」（旗の印）から、問題の誤りや表示の不具合を送れます。報告するかどうかは自由です。送らなくても、アプリを使えます。
  • 自動では送りません。利用者が送信を選んだときに送信します。

送る情報

  • 入力した内容：利用者が書いた文
  • 問題の情報：冊子 ID、冊子の題名、問の番号
  • アプリと端末の情報：アプリの版と build 番号、iOS の版、機種の型番、文字サイズの設定

メールで送る報告は、上記の内容が本文に入ります。メールを送信すると、メールアドレスや表示名などの送信者情報も開発者に届きます。

送らないもの：解答・成績などの学習記録、端末の名前、位置情報、連絡先、写真、広告識別子、購入情報は報告に含めません。報告文に名前・学校名・連絡先などを書かないでください。

送り方と取り消し：「メールで送る」を選ぶとメールアプリが開き、内容を確かめて送信します。送信しなければ、報告は届きません。

5. 使いみちと保存期間

報告は、問題や解説の誤り、表示の不具合を確認して直すことと、アプリの改善に使います。広告、販売、追跡には使いません。個々の報告への返信はしていません。

メールで届いた報告は、受信から90日を過ぎたら削除します。報告をもとに直した内容は、個人が分からない形で開発記録に残ることがあります。

6. 解析・追跡・第三者提供

本アプリには、解析や広告の道具は入っていません。広告配信やアクセス解析も行いません。

AIでの仕分け：報告画面の「AIでの仕分けに使ってよい」は、初期状態ではオフです。オンにした報告だけが仕分けの対象になり、オフのままでも報告を送れます。届いた報告の要約を、OpenAI と Anthropic のAIで仕分け・確認します。要約には、冊子や設問の情報、アプリの版、実行環境を含みます。AIの結果だけで問題や答えを変更することはありません。OpenAI と Anthropic は Apple 以外の会社です。渡した資料の扱いは、それぞれの会社の方針によります。

これ以外の目的で情報を販売したり、第三者に提供したりすることはありません。

7. お子様のプライバシー

本アプリは高校生以上の学習者を主な対象としています。13歳未満の方が利用する場合は、保護者の方と一緒に本ポリシーをご確認ください。

8. 本ポリシーの改定

当方は、必要に応じて本ポリシーを改定することがあります。変更後の内容は、本アプリまたは本ページでお知らせします。
